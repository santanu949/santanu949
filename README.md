## 🔬 Current Focus & Research Interests

- **RAG Pipelines** — Building retrieval-augmented generation systems for domain-specific intelligence. ConvoLens processes 191K+ messages with local embeddings because relying on external APIs at that scale is neither cheap nor reliable.

- **Autonomous Decision Systems** — Real-time data processing, anomaly detection, and automated response orchestration. ACIS monitors 25+ Mumbai zones because civic infrastructure shouldn't depend on someone watching a dashboard.

- **Smart Contract Security** — Automated vulnerability scanning and audit report generation using LLMs. Smart Analyzer exists because manual audits don't scale and most developers can't afford professional ones.

- **Edge AI & IoT** — Deploying ML models on resource-constrained hardware. The waste sorting unit runs inference on Arduino because not every problem needs a GPU cluster.

- **Civic Tech** — Building tools for public infrastructure, legal access, and urban monitoring. Nyayasetu exists because accessing the justice system shouldn't require knowing someone who knows someone.
